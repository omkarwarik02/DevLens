# DevLens 🔍

AI-Powered Code Review Tool for Modern Developers.

## What is DevLens?

DevLens is a full-stack web application that allows developers to paste any code and get instant AI-powered feedback on bugs, security issues, and performance improvements.

## Features

- 🤖 AI Code Review — paste code, get instant feedback
- 🐛 Bug Detection — find hidden logic errors and edge cases
- 🔒 Security Audits — detect vulnerabilities before they ship
- ⚡ Performance Insights — optimize bottlenecks
- 📜 History Tracking — save and track all your reviews

## Tech Stack

### Frontend
- React + TypeScript
- React Router
- React Query
- Tailwind CSS

### Backend 
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
- Groq AI API

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```
